# cutlog 画面別 要件定義（web 版の棚卸し）

`web/index.html` と `web/app.js` を読み、**振る舞い**を画面ごとに書き出したもの。
Flutter 版はこれを満たすことを目標にする。行番号は `web/app.js`。

凡例: ✅ = Flutter 実装済み / ⛔ = 未実装 / △ = 一部のみ

---

## 0. 全画面に効く土台

| 事項 | 仕様 | 状態 |
| --- | --- | --- |
| API | `/api` 配下。401 なら state をクリアしてログイン画面へ（L35-45） | ✅ |
| トースト | 同時に1本だけ。既定 2600ms、失敗系は 4000〜6000ms（L47-53） | ✅ |
| 未処理の失敗 | 書き込みは訳を返す作りにして、呼ぶ側が知らせる | ✅ |
| モーダル | 背景タップ・×・Esc・**下へ 110px 超スワイプ**で閉じる（L536-620） | ✅（標準の札に委譲） |
| 画面遷移 | 深さで出し分け。奥は下から、戻りは上から | ✅ |
| 時刻 | `fmtTime` = `takenAt` から `tzOffset` 分を引いた `HH:MM`（L55-58） | ✅ |
